## 快速开始

### 第一次使用

1. **打开应用**
   - 访问应用 URL
   - 等待地图加载完成

2. **了解工作流**
   - 查看顶部的工作流指示器
   - 了解三个阶段：国家区域 → 行政区 → 导出

3. **开始制作地图**
   - 从"国家区域阶段"开始
   - 使用搜索或 AI 分析添加区域
   - 完成后进入下一阶段

### 5 分钟快速教程

1. **添加国家区域** (1 分钟)
   - 在搜索框输入国家名称（如"中国"）
   - 点击搜索结果
   - 区域自动添加到地图

2. **添加标注** (1 分钟)
   - 点击"添加标记"按钮
   - 在地图上点击位置添加标记
   - 添加文字标签（可选）

3. **导出地图** (1 分钟)
   - 点击"下一步"进入导出阶段
   - 预览地图
   - 选择导出选项并下载

## 功能使用说明

### 1. 工作流阶段

#### 国家区域阶段

**功能**: 选择国家/地区级别的区域

**操作步骤**:
1. 在搜索框输入国家名称或坐标
2. 点击搜索结果添加区域
3. 调整区域样式（颜色、透明度）
4. 控制边界线显示（显示/隐藏、填充/轮廓）
5. 添加标记和文字（可选）
6. 点击"完成"或"下一步"进入下一阶段

**AI 文本分析**:
- 粘贴文本到搜索框
- 点击"AI 分析"按钮
- 查看提取的地理位置列表
- 确认选择并添加到地图

#### 行政区阶段

**功能**: 选择行政区级别的区域

**操作步骤**: 同国家区域阶段，但选择的是省/州/市级别的区域

**提示**: 可以跳过国家区域阶段，直接进入行政区阶段

#### 导出阶段

**功能**: 预览和导出最终地图

**操作步骤**:
1. 预览地图（2D/Globe 视图切换）
2. 调整视图（缩放、平移、旋转）
3. 选择导出选项：
   - 格式：PNG（透明背景）或 JPG（较小文件）
   - DPI：150（快速）、300（标准）、600（高质量）
   - 尺寸：预设尺寸或自定义尺寸
4. 点击"导出"按钮
5. 等待导出完成并下载文件

### 2. 搜索功能

#### 地名搜索

- 输入国家或地区名称
- 系统自动搜索匹配结果
- 点击结果添加到地图

#### 坐标搜索

- 输入经纬度坐标（格式：`纬度,经度` 或 `经度,纬度`）
- 系统定位到坐标位置
- 可以选择该位置附近的区域

#### AI 文本分析

- 粘贴包含地理信息的文本
- 点击"AI 分析"按钮
- 等待分析完成（显示进度）
- 查看提取的地理位置列表
- 确认选择并添加到地图

### 3. 标注功能

#### 添加标记

1. 点击"添加标记"按钮
2. 在地图上点击位置
3. 选择标记类型（点/圆圈/图标）
4. 设置标记属性（颜色、大小）
5. 点击"确认"完成添加

#### 添加文字标签

1. 点击"添加文字"按钮
2. 在地图上点击位置
3. 输入文字内容
4. 设置文字属性（字体大小、颜色、背景）
5. 点击"确认"完成添加

#### 管理标注

- **标注列表**: 查看所有标注
- **编辑标注**: 点击标注进行编辑
- **删除标注**: 选择标注并删除
- **批量操作**: 选择多个标注进行批量编辑或删除

### 4. 样式调整

#### 区域样式

- **颜色**: 点击颜色选择器选择颜色
- **透明度**: 拖动透明度滑块调整
- **边界模式**: 选择填充或轮廓模式

#### 边界线控制

- **显示/隐藏**: 切换边界线显示
- **模式**: 填充（Fill）或轮廓（Outline）
- **颜色**: 自定义边界线颜色
- **透明度**: 调整边界线透明度

**注意**: 国家区域和行政区阶段的边界线独立控制

### 5. 视图控制

#### 2D 视图

- **缩放**: 鼠标滚轮或缩放按钮
- **平移**: 拖拽地图
- **重置**: 点击"重置视图"按钮

#### Globe 视图

- **切换**: 点击"Globe 视图"按钮
- **旋转**: 拖拽 Globe
- **缩放**: 鼠标滚轮
- **重置**: 点击"重置视图"按钮

**注意**: Globe 视图仅在导出阶段可用

## 最佳实践

### 1. 快速制作地图

- 使用 AI 文本分析快速提取地理位置
- 使用自动填充功能（自动颜色、自动标签）
- 选择较低的 DPI 进行快速导出（150 DPI）

### 2. 高质量地图制作

- 精确选择区域（使用坐标搜索）
- 仔细调整样式和颜色
- 添加详细的标注
- 选择高 DPI 导出（300-600 DPI）

### 3. 演示地图制作

- 使用 Globe 视图增强视觉效果
- 选择品牌色作为区域颜色
- 添加关键标记和标签
- 预览效果后再导出

### 4. 教学地图制作

- 使用清晰的轮廓模式
- 添加清晰的文字标签
- 选择适合打印的 DPI（300 DPI）
- 使用 PNG 格式（透明背景）

### 5. 研究地图制作

- 精确选择区域和数据
- 添加详细的标注和图例
- 使用高质量导出（600 DPI）
- 验证数据的准确性

## 常见问题

### Q1: 如何快速添加多个区域？

**A**: 使用 AI 文本分析功能，粘贴包含多个地理位置的文本，系统会自动提取并显示列表，你可以选择多个结果一次性添加。

### Q2: 可以跳过某个阶段吗？

**A**: 可以。每个阶段都提供"跳过"按钮，你可以跳过不需要的阶段直接进入下一阶段。

### Q3: 可以回到之前的阶段编辑吗？

**A**: 如果启用了阶段导航功能，你可以点击工作流指示器上的已完成阶段，回到该阶段进行编辑。

### Q4: AI 分析的结果不准确怎么办？

**A**: AI 分析结果会显示置信度评分，你可以：
- 只选择高置信度的结果
- 手动搜索和添加区域
- 编辑已添加的区域

### Q5: 导出的地图质量不够高怎么办？

**A**: 
- 选择更高的 DPI（300 或 600）
- 选择 PNG 格式（无损）
- 选择更大的尺寸
- 注意：高质量导出需要更长的处理时间

### Q6: Globe 视图导出有问题怎么办？

**A**: Globe 视图导出可能有限制，建议：
- 使用 2D 视图导出
- 如果必须使用 Globe 视图，系统会自动转换为 2D 投影后导出

### Q7: 如何保存我的工作？

**A**: 当前版本不支持保存功能（未来版本会支持）。建议在完成地图后立即导出，或者使用浏览器的本地存储功能（刷新页面可能丢失数据）。

### Q8: 支持哪些浏览器？

**A**: 支持 Chrome、Firefox、Safari 的最新版本。建议使用 Chrome 或 Edge 以获得最佳体验。

### Q9: 可以离线使用吗？

**A**: 当前版本需要网络连接（用于加载地图数据和 AI 分析）。未来版本可能支持离线模式。

### Q10: 地图数据来源是什么？

**A**: 使用 GADM（Global Administrative Areas）数据，提供全球行政区划数据。

## 快捷键参考

### 通用快捷键

- `Ctrl/Cmd + Z`: 撤销
- `Ctrl/Cmd + Y`: 重做
- `Esc`: 关闭对话框/取消操作
- `Enter`: 确认/搜索
- `Tab`: 切换焦点

### 地图操作

- `鼠标滚轮`: 缩放地图
- `鼠标拖拽`: 平移地图
- `双击`: 放大/详细查看
- `右键点击`: 上下文菜单（如果有）

### 标注操作

- `点击地图`: 添加标记/标签（在添加模式下）
- `点击标注`: 选择标注
- `Delete`: 删除选中的标注

### 视图操作

- `Ctrl/Cmd + 0`: 重置视图
- `Ctrl/Cmd + +`: 放大
- `Ctrl/Cmd + -`: 缩小
