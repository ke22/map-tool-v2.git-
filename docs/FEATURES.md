## 功能详细说明

### 1. 分阶段工作流

#### 国家区域阶段

**功能描述**: 用户选择国家/地区级别的区域

**交互流程**:
1. 用户进入国家区域阶段
2. 搜索或使用 AI 分析添加国家/地区
3. 区域自动填充到地图
4. 调整颜色和样式
5. 添加标记/文字（可选）
6. 完成或跳过进入下一阶段

**技术实现**:
- WorkflowState.countryStage 存储状态
- BoundaryManager 管理边界渲染
- 支持 GADM Level 0 数据

#### 行政区阶段

**功能描述**: 用户选择行政区级别的区域

**交互流程**:
1. 用户进入行政区阶段
2. 搜索或使用 AI 分析添加行政区
3. 区域自动填充到地图
4. 调整颜色和样式
5. 添加标记/文字（可选）
6. 完成或跳过进入导出阶段

**技术实现**:
- WorkflowState.administrationStage 存储状态
- BoundaryManager 管理边界渲染
- 支持 GADM Level 1+ 数据

#### 导出阶段

**功能描述**: 用户预览和导出最终地图

**交互流程**:
1. 用户进入导出阶段
2. 预览地图（2D/Globe 视图）
3. 调整视图和设置
4. 选择导出选项（格式、DPI、尺寸）
5. 导出地图文件

**技术实现**:
- ExportManager 处理导出逻辑
- html2canvas 或 Mapbox Static Images API
- Globe 视图转换为 2D 投影

### 2. 搜索和自动填充

#### 统一搜索入口

**功能描述**: 提供统一的搜索界面，支持多种搜索方式

**搜索方式**:
- **地名搜索**: 通过地名查找地理位置
- **坐标搜索**: 通过经纬度坐标查找
- **AI 文本分析**: 从文本中自动提取地理位置

**技术实现**:
- GeoResolverAgent 处理地名和坐标搜索
- GeoExtractorAgent 处理 AI 文本分析
- 搜索结果自动填充到当前活动阶段

#### AI 文本分析

**功能描述**: 用户粘贴文本，AI 自动提取地理位置

**交互流程**:
1. 用户粘贴文本到搜索框
2. 系统识别为文本分析模式
3. GeoExtractorAgent 分析文本
4. 显示提取结果（列表预览）
5. 用户确认后填充到地图

**技术实现**:
- Gemini API 调用（通过代理服务器）
- 置信度评分显示
- 预览确认机制

#### 自动填充

**功能描述**: 搜索或 AI 分析后自动执行的操作

**自动操作**:
1. **自动 Zoom to**: 地图自动缩放并定位到区域
2. **自动填充颜色**: 根据区域数量自动分配颜色
3. **自动添加中文标签**: 自动添加区域名称标签

### 3. 标记和文字（独立层）

#### 标记管理

**功能描述**: 在地图上添加和管理标记点

**标记类型**:
- 点标记（Point）
- 圆圈标记（Circle）
- 图标标记（Pin/Icon）

**功能特性**:
- 添加/删除标记
- 编辑标记属性（颜色、大小、图标）
- 标记列表视图
- 批量编辑
- 层级控制（z-index）

#### 文字标签管理

**功能描述**: 在地图上添加和管理文字标签

**标签属性**:
- 文字内容
- 字体大小
- 颜色
- 背景颜色
- 位置（坐标）
- 层级（z-index）

**功能特性**:
- 添加/删除标签
- 编辑标签属性
- 标签列表视图
- 批量编辑
- 搜索和筛选

### 4. 边界线控制

**功能描述**: 控制每个阶段的边界线显示

**控制选项**:
- **可见性**: 显示/隐藏边界
- **模式**: 填充（Fill）/ 轮廓（Outline）
- **颜色**: 自定义颜色
- **透明度**: 0-1 范围

**阶段独立**: 每个阶段（国家区域、行政区）独立控制

### 5. 导出功能

#### 导出功能技术方案

**实现方式**:
1. **html2canvas 方案**（主要）
   - 优点: 简单易用，支持自定义样式
   - 缺点: Globe 视图可能有问题，性能限制
2. **Mapbox Static Images API**（备选）
   - 优点: 高质量，支持 Globe
   - 缺点: 需要 API 调用，成本考虑
3. **Globe 视图特殊处理**
   - Globe 视图转换为 2D 投影后导出

#### 导出设置

**格式选择**:
- PNG（支持透明背景）
- JPG（较小文件大小）

**DPI 选择**:
- 150 DPI（快速导出）
- 300 DPI（标准质量）
- 600 DPI（高质量）

**尺寸设置**:
- 预设尺寸（1920x1080, 2560x1440 等）
- 自定义尺寸

#### 导出进度反馈

**进度指示**:
- 进度条显示
- 百分比显示
- 预计剩余时间

## 功能交互设计

### 阶段切换交互

```
用户点击"下一步"按钮
  ↓
系统验证当前阶段是否完成（可选）
  ↓
显示确认对话框（如果阶段未完成）
  ↓
用户确认切换
  ↓
执行阶段切换动画
  ↓
更新工作流状态
  ↓
触发阶段切换事件
  ↓
更新 UI（工作流指示器、控制面板）
```

### 搜索交互

```
用户在搜索框输入
  ↓
系统检测输入类型（地名/坐标/文本）
  ↓
如果是文本 → 显示"AI 分析"按钮
  ↓
用户点击搜索或 AI 分析
  ↓
显示加载状态
  ↓
返回搜索结果
  ↓
显示结果列表（如果是多个结果）
  ↓
用户选择结果
  ↓
自动填充到地图
  ↓
显示成功提示
```

### AI 分析交互

```
用户粘贴文本
  ↓
系统识别为文本模式
  ↓
显示"分析文本"按钮
  ↓
用户点击分析
  ↓
显示加载状态（进度指示）
  ↓
返回分析结果
  ↓
显示结果预览（列表）
  ↓
用户确认选择
  ↓
填充到地图
  ↓
显示成功提示
```

## 功能状态机

### 工作流状态机

```
[初始状态]
  ↓
[国家区域阶段: pending]
  ↓ (用户操作)
[国家区域阶段: active]
  ↓ (完成/跳过)
[国家区域阶段: completed/skipped]
  ↓
[行政区阶段: pending]
  ↓ (用户操作)
[行政区阶段: active]
  ↓ (完成/跳过)
[行政区阶段: completed/skipped]
  ↓
[导出阶段: active]
  ↓ (导出完成)
[完成状态]
```

### 阶段状态转换

```
pending → active (用户进入阶段)
active → completed (用户完成阶段)
active → skipped (用户跳过阶段)
completed → active (用户回溯编辑)
skipped → active (用户回溯编辑)
```

### 标注状态

标注（标记和文字）独立于阶段状态，可以在任何阶段添加/编辑/删除。
